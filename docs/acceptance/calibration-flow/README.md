# 校准到徒步闭环修复（2026-10-04）

本次按用户报告修复校准步骤过多、后台中断后重来及无法进入游戏的问题。A 模块修复，关联 Issue #7；消费既有 B #8 徒步入口，没有修改 `src/game/`、`src/scene/` 或共享契约。

本地分支 `codex/m3-attention-calibration-fix` 基于已有联合入口 `4b509eb`；远程 main 只读核对为 `e624c53`。原根工作目录与其他分支保持原状。未推送、合并或代替真人审核。

## 改动与依据

- 原位置校准 26 项（两轮九点 + 每轮四个头姿），改为 22 项（两轮九点 + 四个头姿各一次）。保持九点空间覆盖、每项至少 10 个稳定样本、原岭回归候选及交叉验证。
- 原屏内外校准 20 项改为 10 项：复用当前会话位置校准中的两轮真实屏内特征，仍分别采两轮五个屏外方向。模型仍按轮留出评估，不复用任何独立验证数据。
- 保留独立五点位置验证和十项屏幕状态验证。总项数从 61 降到 47，减少约 23%。这不是 47 次按钮点击；普通圆点自动推进，屏外/头姿项需确认准备好。
- 新增“连续校准与验证”，自动串联四阶段；失败停止串联、显示原因，保持注视交互关闭。可仅重新执行失败阶段。
- 原验证用目标调度频率 15Hz 生成分母；实际约 11.7Hz 时，即使每个推理结果都有效，也会被填入大量 `missing-sample`。现以已定义的最低工作频率 10Hz 划分 100ms 时间窗，每窗最多一个测量，空窗仍为无效/未知，所有窗均进入分母。位置误差门槛（中位 ≤8%、P90 ≤15%、有效率 ≥90%）和屏幕状态误报/召回门槛均未更改。这是采样覆盖统计方法的修正，应在后续真人报告中标注该版本，不能与旧版有效率不加区分地比较。
- 样本不足最多自动重试当前点两次，之后等待用户重试当前点；切后台也仅废弃当前点，不丢弃此前完成项。屏幕尺寸/全屏变化仍使整个映射失效，防止错坐标进入游戏。
- 场景运行时停止隐藏校准页的逐帧 DOM、眼部预览和诊断更新；摄像头 Worker 与游戏订阅持续工作。

## 操作

首页选择时长 → 校准并开始 → 进入全屏 → 开启摄像头 → 连续校准与验证 → 校准完成，进入徒步 → 开始徒步。保持窗口尺寸及坐姿不变。结束后查看本地结果、下载记录；“再走一段”复用仍有效的当前会话校准。返回首页释放摄像头。

如果验证未通过，查看测量与诊断并重试对应阶段。不能为保证能进入而跳过验证。位置/状态验证通过也不代表已经完成多人精度验收。

前三项通过，逻辑测试 46/46；构建保留已有约 893KB 场景包体积警告。最初沙箱内 tsx 用户信息读取和 esbuild 目录读取失败，之后逻辑测试在授权执行环境通过，最终构建使用 native 配置加载通过。

`calibration-flow-check.cjs` 使用本机 Edge，须先设置 `PLAYWRIGHT_MODULE`；`HIKE_URL` 可指向开发或生产预览入口。Canvas + Worker 合成输入约 11.8Hz，不是摄像头精度或真实模型推理性能。开发入口及生产预览均已实际通过：后台暂停并保留进度、完整 47 项串联、独立验证失败禁入及恢复、实际森林行走、暂停/恢复、提前结束、本地保存/JSON 下载、再次开始和回首页关闭摄像头。最终生产检查数据见 [checks.json](checks.json)，无页面脚本错误。短时约 9.55 秒行走、10.66 米，平均 32.97 FPS；这不是稳定 30 FPS 或 15 分钟联合验收。合成 camera-shaped 记录只在隔离浏览器中检查，随后删除，不作为真人数据留存。

检查图均带合成输入标记：[验证](validated-synthetic.png)、[行走](walking-synthetic.png)、[结束](result-synthetic.png)。最初暂停测试在 UI 刷新之前读取文字，出现一秒差异；修正测试等待暂停状态后复验通过，不是修改游戏计时规则。

异常恢复检查通过，见 [recovery.json](recovery.json)：无有效样本最多自动重试两次，保留当前点等待恢复；恢复后可推进；Worker 故障退出任务且保留原错误原因，摄像头可重启；取消不会启用交互，停止释放流。最终类型检查和生产构建再次通过。

既有徒步回归以 `HIKE_CHECK_OUT=docs/acceptance/calibration-flow/hike-regression` 运行，避免覆盖历史证据。12 组检查通过、无页面错误，见 [回归数据](hike-regression/checks.json)：5/10/15 分钟选择、权限拒绝、真实场景上的合成注视行走及转向、离屏停止/天气恢复、无效传感器不算离屏、暂停/恢复、30 秒反馈上限、音频调度、提前与自动结束/重复保存防护/历史重载、同页释放和重建场景、模拟历史不计真实成就、手动场景/地图/天气。15 分钟自动完成使用时钟快进，不是实际运行 15 分钟。该回归约 39 秒有效运行平均 40.11 FPS、帧耗时 P95 42.5ms，自动画质二级、800×500 绘制；P95 超过 33.3ms，不能宣称稳定 30FPS 或原画性能达标。
