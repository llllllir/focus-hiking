## M2-B：注视系统的交互端

制作可独立使用的三个大目标测试界面，显示停留进度、信号与校准状态。按 CSS 视口坐标提交 TargetRegion，完成路标投影适配。消费 A 信号，不复制视觉模型。

交给 agent：实现 M2-B，三个区域不重叠，初始目标至少 20vw×24vh；标明 camera/simulated/manual，支持信号无效提示；实测界面与 A 真人测试配合。

## M3-B：注视驱动路径

确认路标后沿路径移动，移动期间禁用目标，结束后重新投影；防止重复推进。支持 5/10/15 分钟体验、暂停重启及信号异常状态。与 A 完成 15 分钟联合性能验收。

交给 agent：实现 M3-B，用接口消费事件，不调用摄像头；写状态机有效测试。性能不足先降阴影/植被/分辨率，不擅自移除注视系统。

## M4-B：地图细化与温和事件

细化同一地图，提供雾、落叶遮挡和改道等环境事件，通过 TrainingCommand 触发并回传 SceneEvent。实现任务提示、结束反馈 UI；自由观景没有惩罚。

交给 agent：实现 M4-B，先冻结任务/反馈契约；不在 scene 内另写一套注意力规则，不做强闪烁、惊吓、多地图和排名。
