## 用户操作

首页选择时长 → 校准并开始 → 进入全屏 → 开启摄像头 → **轻松校准并准备徒步** → 验证完成后点击高亮的进入徒步按钮 → 开始徒步。

位置校准自动走完15项，不再要求上下左右转头；屏幕内外校准10项（两轮各五个屏外方向），屏内特征复用本次位置采样。另保留5项位置检查、10项屏幕状态检查，完整引导共40项，比phase7的47项少7项，比最初61项少21项。普通圆点无需逐项点击；屏外方向需读完提示后确认开始。采样失败/切后台仅重试当前点。

## 策略及具体阈值

所有入口阈值集中于 `src/attention/entry-policy.ts`，策略标记 `easy-entry-v1`。这是游戏可用性选择，不能当作原M2验收标准。

| 项目 | phase7 | 轻松进入 |
| --- | --- | --- |
| 位置采样 | 22项 | 15项（首轮完整九点 + 次轮四角/中心 + 中心再采一次） |
| 屏幕内外采样 | 10项 | 10项，保留两轮并复用屏内数据 |
| 每项稳定样本 | 至少10，保留比例60% | 至少8，保留比例50% |
| 位置有效率 | ≥90% | ≥70% |

| 位置P90误差 | ≤15% | ≤25% |
| 状态验证离屏误报屏内/屏内误报离屏 | 各≤5% | 各≤20% |
| 屏内/离屏召回 | 各≥90% | 各≥70% |
| 验证无法判断比例 | ≤10% | ≤30% |

保留原模型、本地Worker、稳定采样剔除、原始未裁剪预测及独立验证数据隔离。所有九个位置仍采到；第二轮保留五个不同屏内位置，满足按轮训练的屏内外分类器，不把一个样本伪装成两轮。训练/独立验证样本不混用。

无脸、闭眼、摄像头断开、过期信号、后台以及明显偏离坐姿仍停止交互。完全无法判断、反向分类或误差过大仍不能开启注视，不提供把失败伪装通过的路径。放宽以后可以更容易进入，但误走、方向误差或离屏误判可能增加，这是用户授权的取舍。

位置及屏幕CSV新增 `entryPolicy` 列，避免不同门槛报告混淆。共享 AttentionPort/场景接口未改，B源文件未改。已有徒步历史摘要未变更结构，因此跨版本历史表现不能直接用于证明精度或能力提高。
