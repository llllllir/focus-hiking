# 此刻山间：本机环境存档与三次免测体验

日期：2026-10-04。用户在 phase 8 后授权本轮更名和本地环境复用；沿用 `codex/m3-attention-calibration-fix`，不改写 phase 7/8 检查点，不合并或删除其他分支。相关工作属于 A 的摄像头/校准与组合首页，关联 Issue #7、#4。

## 名称与首页

名称为 **此刻山间 · Here in the Mountains**，主 slogan 为 **目光慢下来，此刻在山间。** 首页保留同一森林背景，左侧为时长、当前环境与校准入口，右侧为环境存档卡片、新建和删除操作。页面标题、描述、校准页和游戏顶栏同步更名。B 的 `src/game/app.ts` 仅按用户明确更名要求修改品牌文字，不更改场景或游戏逻辑；共享契约不变。

内部包名、仓库地址和既有徒步存储键保持兼容，避免更名导致原记录消失。环境存档和徒步成绩是两个独立的数据集合。

## 成功存档

1. 首页选择或新建环境，例如“书桌 · 日间”。
2. 开启全屏、摄像头并完成连续校准/独立验证。
3. 位置与屏幕状态两项独立验证均达到当前体验门槛后，点击 **保存成功环境**。未通过不能保存成“成功”。
4. 下次从同一浏览器、同一地址打开，点击该卡片的 **同一环境，直接进入**，自动开启全屏及摄像头，加载个人模型，不重复校准与五点/屏幕验证。

加载时匹配屏幕尺寸、全屏视口、像素比例、视频分辨率与摄像头标识的 SHA-256 摘要。不会存储原始设备标识。“同一环境”不能自动证明房间、光照、坐姿、眼镜和屏幕相对位置一致；页面明确要求使用者在点击时确认这些条件。检测到设备或显示条件不匹配会停止摄像头并提示选择/新建对应环境，不把旧模型冒充新环境的验证结果。

摄像头授权仍由浏览器控制。免测免去的是校准测试，不是实时眼动输入。进入后显示“已加载本机成功环境存档 · 本次未重新验证”；仍要有有效实时眼动信号才开始行走。

## 三次后不再强制测试

每个具名环境单独累计实际测试次数，并在首页和校准页显示。完整连续引导算一轮；单独完成五点验证或屏幕验证算一轮；一轮采样在当前点自动重试两次仍不足时算一轮失败。取消、仅点击开始、权限拒绝、切后台以及同一点的自动重试不额外增加次数。同一轮失败后继续采样或收到多次完成回调只计一次。

累计 **3 次** 后，即使没有通过验证，也会解锁 **已测试三次，直接体验**；第三轮采样失败的覆盖层也提供此按钮，不要求先完成剩余测试。首页卡片变成 **不再测试，直接体验**，刷新/重开仍保留解锁状态。更换环境不能继承另一环境的次数。

已有可用个人模型时继续使用；若三次都未能生成完整模型，以现有眼部几何提供基础方向估计，不更换 MediaPipe 主模型。基础模式没有可靠的个人映射或屏幕内外精度保证，始终标记 **免测体验 · 尚未通过精度验证**，不修改验证通过标记。该模式仍使用真实实时摄像头特征，不使用模拟坐标，不将闭眼、无人脸、失效或后台转换成有效样本。停止或校准重置会撤销当前会话的基础模式。

phase 8 已有的“完成模型后未达标也可进入”保留；三次解锁额外覆盖尚未生成模型及下次会话直接进入的情形。原 M2 真人验收标准没有因此通过，基础模式数据不能作为准确率或训练效果证据。

## 存储与失败处理

存储键为 `here-in-the-mountains.environments.v1`，最多8个环境，仅位于当前浏览器当前站点的 localStorage。保存拟合系数、归一化参数、姿态范围、聚合眼部基线、模型版本、环境签名、次数及保存时间；不保存帧、眼部预览图、逐帧特征序列或训练样本。用户本轮授权覆盖此前“校准参数默认只限会话”的默认规则；个人参数仍不进入 Git 或服务器。

成功模型与最近一次未达标模型分开，失败重试不会覆盖已保存的成功模型。读取存档时校验版本、数组维度、有限数值、尺度及范围，保存采用字段白名单。损坏数据保留原文，不默默覆盖；用户可点击“清除全部环境存档”恢复。存储不可用或配额不足时显示无法持久保存，本次会话仍可使用。删除环境不会删除徒步记录。

沿用已安装依赖，浏览器脚本设置 `PLAYWRIGHT_MODULE` 与 `HIKE_URL`，不提交本机绝对路径。59项逻辑测试、类型检查和生产构建通过；构建保留既有场景大包提示。浏览器证据见 [本轮检查](acceptance/environment-archives/README.md)，全部为合成输入，不是真人校准档案。

真人跨日复用、座位与光照变化、不同摄像头、基础模式误走/离屏误判及长时性能仍需实际试用。不能声称环境存档保证下次精度；如果体验明显不准，应新建环境或重新校准。
