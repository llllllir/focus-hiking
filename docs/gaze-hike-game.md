## 使用流程

默认首页选择 5 / 10 / 15 分钟，鼠标点击“校准并开始”，再按现有摄像头流程授权、校准、验证和进入全屏。校准及屏内外验证未达到现有门槛不能进入徒步。完成准备后点击开始，以新鲜、有效的真实屏内样本平滑控制方向并前进。

明确离屏立即停步，转阴天并播放由远及近的雷声，单次反馈最多 30 秒。提前回到屏内立即晴天继续；超过 30 秒仍离屏时恢复天气但继续停步。闭眼、无人脸、信号过期等只暂停运动，单独计入无法判断时间，不算注意力失败。全屏/校准失效或页面后台会暂停，返回后需重新准备或手动继续。

可以暂停、结束、重新选择时长、重新校准或回首页。结束保存本浏览器全部汇总记录，展示实际时长、距离、屏内保持率、信号覆盖、离屏与恢复次数、成就及相同时长的有效历史比较。低覆盖率不展示保持率成绩。可下载 JSON 存档；暂未实现导入、跨浏览器同步或账户云存档。

自由探索仍通过 `?mode=explore` 进入，保留地图自身位置、路线偏离、晴雨天气及原画质选项。摄像头诊断仍通过 `?mode=gaze-test` 进入。

## 实现与修复

- `src/hike-experience.ts` 组合现有 A 校准界面和 B 游戏；`src/main.ts` 选择入口。
- `src/game/hike-game.ts` 控制地形步行、方向平滑、计时状态、天气反馈、结果与存档界面。行走使用现有地形高度与碰撞，禁止手动键盘绕过离屏停止。
- `src/training/hike-session.ts` 限制样本年龄、拒绝倒序/未来样本，分离屏内、离屏、未知和暂停时间，结束幂等。确认后的天气事件不因短暂样本空隙重复启动雷声。
- `src/training/hike-archive.ts` 白名单版本存储、读写失败提示、损坏存档保护、真实来源趋势与明确成就条件。记录不保存摄像头帧、逐帧注视、特征或个人校准。
- 云天与降雨分开：阴天不产生雨丝，也不突然弄湿地面；雨天原功能保留。
- 原三角网每帧射线地形采样改用现有高度采样；缓存雨滴落点；自动档降低分辨率、阴影范围和更新频率，保留原画档。
- 修复同页退出再进入时 WebGPU 设备与着色器缓存不匹配。释放场景专用 GPU 资源，复用设备及引擎少量共享帧缓冲；设备丢失要求重新加载，不宣称长期内存泄漏已完全排除。
- 修复隔离 worktree 位于父级 `.tools` 时 Vite 将整个源码忽略的问题，忽略范围只针对当前项目自身工具目录。

## 复验及剩余工作

见 [浏览器与性能记录](acceptance/gaze-hike/README.md) 和 [规则定义](hike-rules.md)。测试装置直接发送标记为 simulated 的样本，不证明真实眼动精度。15 分钟自动完成用模拟时钟推进，不是实际 15 分钟真人运行。

尚需人工测试真实摄像头校准、全屏切换、长时联合模型推理性能、音量及雷声听感、视觉风格。原有动物是程序化骨骼模型，距用户要求的专业写实建模仍有明显差距。自动画质的性能结果不代表原画档达到 30FPS。原聊天四张图片未取得，不能宣称已提取或逐图复现。

存档只保留体验汇总并默认本地保存，不发送服务器。场景保存前已移除 Blender/PNG 内的本机路径元数据；一次中止的 Git Data API 准备尝试曾上传未引用的原始素材对象，其中含本机路径元数据，未写入分支引用，最终公开提交使用清理版本。没有摄像头帧或访问令牌写入提交；不重写其他人的历史。
