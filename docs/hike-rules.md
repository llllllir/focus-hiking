# 本地眼动徒步规则与记录

用户本次明确授权从场景保存继续实现完整徒步，覆盖原计划 M3/M4 的部分行为；不因此宣布 M2 或联合验收完成。对应 M3-A #7、M3-B #8。单 agent 在隔离 worktree 顺序实现；原眼动目录保留，A 的计时/记录与 B 的场景消费保持代码归属，不冒用 RUI-TW，不 merge 或自行审批。

沿用共享 AttentionPort/GazeSample，不增加共享契约字段。真实摄像头仍需本地模型、个人位置与屏幕内外校准、独立验证和全屏许可。只有 `source=camera` 且屏内有效坐标驱动行走；已稳定输出的 `invalidReason=off-screen` 触发离屏。闭眼、无人脸、姿态/校准范围异常、无法判断、过期信号和模拟输入停止运动，但不算离屏。样本最长有效 250 ms，拒绝未来、倒序和重复时间戳。

选择 5/10/15 分钟后开始。体验计时包含真实离屏和无法判断时间，手动暂停/后台时间除外；后台回来需要手动继续及新鲜样本。只有已确认屏内时按注视方向平滑转头和前进，逐帧限制步长并使用地形/障碍碰撞，不跳转到遥远目标。持续离屏立即停步，阴天雷声反馈上限 30 秒，持续离屏超过上限仍停步；提前回到屏内立即恢复晴天行走。每次离屏只触发一段天气反馈；传感器问题不会创建离屏次数。

时间结束、主动结束或离开页面结束一次体验，同一记录 ID 只保存一次。支持中途暂停与继续。存档在本浏览器本地，按版本保存每次汇总，保留全部次数，不设置悄悄删除的条数上限；读写失败和存储空间不足明确提示，保留损坏的原存档，不自动覆写，可下载当前汇总。

存档白名单：随机记录 ID、来源、开始日期、计划时长、完成/提前结束、体验时间、屏内/离屏/无法判断毫秒、离屏与恢复次数、实际距离、屏内保持率、信号覆盖率和帧率。没有摄像头帧、关键点、逐帧注视位置、模型/校准参数、姓名或设备序列号。记录只在当前浏览器来源可见；换浏览器/站点不能自动迁移。

屏内保持率 = 屏内时间 /（屏内时间 + 已确认离屏时间）；无法判断时间单独展示，不能当作分心，也不能隐藏其低覆盖率。历次比较仅限真实来源、相同时长、至少 60 秒可判断数据、覆盖率至少 70%；不足时不计算提升。展示的是屏内保持率变化（百分点），不是心理注意力改善证明。成就使用明确条件：开始过一次、完成过一次、覆盖率足够且至少一分钟屏内保持率达到 80%。模拟检查始终标记 simulated，不进入真实趋势或成就统计。

纯逻辑徒步检查实际通过 10 项，全项目 46 项通过。浏览器模拟输入已验证完整计时、天气、运动、存档与重入流程，详见 [集成检查记录](acceptance/gaze-hike/README.md)。真人眼动精度、联合摄像头性能、听感和写实画质仍待人工验收；不将模拟输入冒充真人体验。
