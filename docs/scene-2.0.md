# 场景2.0：B 场景与游戏交接

2026-10-03 用户将“框架场景1.0 · 探索迭代”命名为场景2.0，授权以下同图探索修订。历史验收资料保持原目录。

1. 路段分为溪谷混合林、苔岩／白桦林、开阔山顶。会话种子改变树形比例、朝向、林下灌木／蕨类位置、石块／倒木方向与动物活动相位；地形、路径拓扑和桥位置保持稳定，避免随机生成断路。固定 `?seed=42` 可复现。
2. 身体位置与视觉镜头分开；贴地高度平滑，步幅起伏幅度最多约 0.018m，不增加镜头滚转。暂停冻结视觉位置，系统减少动态效果关闭步幅起伏。
3. 自由探索和路线规划使用同一张地图。自由探索 WASD 行走；路线规划选择地图／目的地，显示预计距离与时间，确认后出发。离小径超过 3m 时提示先走近小径，避免从远处直接横穿森林。手动移动会停止规划行走。
4. 增加白桦、草丛、野花与六只自主活动的环境鹿。鹿使用简单受障碍约束的活动轨迹，尚无骨骼步态、觅食行为或完整动物 AI。模型与颜色纹理由项目自产。
5. 抬高主山与增加三处坡地；山顶可俯瞰溪谷。固定山顶视角改朝山下，不把相对高度变化当作真人舒适度验收。
6. 可行走边界从 130×127m 变为 390×381m；两条横向长度均为原来的三倍，面积九倍。地形从 160×160m 变为 480×480m。
7. 增加岩石、倒木、桥板、第二座溪桥及原创建模纹理。用户“火坡”的含义等待澄清；未自行把它解释为火堆并宣布完成。

同日营地追加：删除原两片式遮棚，改为拱形可进入帐篷。补充铝撑杆、缝线、拉绳／地钉、卷起门帘、窗格、地垫、睡垫与卷毯。入口宽 1.8m、高 2.1m，帐篷最高约 2.65m；墙体阻挡行走，门口保留通道。下方及周边 7.8m 清掉石块／树木，入口到小径也留出净空；地形局部平整，地垫作为可站立表面。没有使用传送或固定内部相机替代实际 WASD 进入检查。

修改归属为 B：scene/game、相应测试、场景资源及文档。A 的注意力／训练实现与冻结共享契约未改。未启用摄像头，不把模拟诊断当作真实眼动。仓库未配置 Git 远程且无提交基线，因此没有可核对的线上 Issue、main 或可创建的远程 PR；本地使用 codex/m1-scene 分支，未提交或合并。
