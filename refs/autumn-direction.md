# 用户秋季视觉方向

2026-10-03 用户新指令覆盖此前初夏配色。本文件记录用户文字参考；另一个图片聊天的最后四张原图尚未取得。

四个参考画面均为写实 3D 游戏环境，16:9 横向、人眼或低位观察视角，画面铺满，没有字幕、界面、水印或黑边。

1. 秋季温带阔叶林：自然粗细/倾斜/间距的高大树干，交错连续树冠；金黄、赭黄、铜橙、深棕叶片，少量暗绿林下植物。林下视点略仰望；低位太阳中央偏右，暖逆光、薄空气雾、柔和光束。深阴影前景、透光中景、明亮远景；起伏林地、落叶、苔石、蕨类、灌木，无明显道路。
2. 针阔混交林中的两只成年雄性驼鹿：中景偏右、朝左，宽大掌状角、长腿、厚肩和深褐毛；粗前景树干部分遮挡近侧动物。云杉下垂层枝围合，浅蓝天空；暗红灌木、枯草、苔藓、枯枝、石头、右下倒木。低饱和橄榄绿/灰棕/暗红，安静偶遇，无攻击或追逐。
3. 秋季森林湿地：近水面低视点，近景雄性绿头鸭向右上飞，一翼高举，另一翼后展；绿头、白颈环、栗胸、灰腹、黄喙、橙脚、可信羽毛/结构。另三鸭中远景；蓝灰微波水、金褐芦苇、针阔混合远岸、小拱桥。天空约占三分之二，晴天侧光，清爽开阔。
4. 秋林木屋：前左观察，中央偏右、单层矩形，正面山墙与右延长侧墙；暗红竖木板、深棕梁柱、灰褐风化双坡顶、浅灰基础。正面两窗、侧面三窗，白框格栅；山墙鹿头角饰、转角电箱，两蓝桶与一红桶。前景苔石矮墙与左侧树干，草地/裸土径/秋林/左侧木栅栏，日间侧光与斑驳阴影。
