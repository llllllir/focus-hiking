# Phase 1 / M1：初步登山场景规格

状态：草案，待负责人核对；创建日期：2026-10-03。Phase 1 暂对应现有计划的 M1 / v0.1，不修改原定阶段门槛或后续日程。

## 负责人、阶段与目标

A（llllllir）负责工程、共享契约、模拟注视与诊断；B（RUI-TW）负责森林场景与游戏控制。交付可启动、可自动游览的初步森林登山体验，让导师能完整观看路线。

依据：[总计划](../../docs/development-plan.md)、[共享接口](../../docs/interfaces.md)、[任务数据](../../docs/project-plan.json)。本地任务数据不是已核对的线上 Issue。

## 用户场景与验收用例

| 编号 | 用户场景 | 可观察的验收结果 |
| --- | --- | --- |
| US1 | 新环境按照说明启动 | 安装和启动步骤可复现，页面显示场景；依赖或 WebGL 失败有可读提示 |
| US2 | 导师观看自动游览 | 单张地图可辨认营地、森林路径、溪流和山顶远景，游览能完成整段路线 |
| US3 | 观看者暂停和重启 | 暂停期间路线进度不增加，恢复连续；重启回到起点且不会叠加动画循环或重复监听 |
| US4 | 开发者查看模拟诊断 | 页面持续标注 simulated，样本、目标及事件可检查，不能误认为真实摄像头输出 |
| US5 | 双方接入与验收 | 分别提交 PR、交叉审查并合入，提供演示与实测；导师确认后才关闭 M1 |

## 允许修改的范围与冻结接口

- A：工程配置、锁文件、入口装配、`src/attention/`、`src/training/`、对应测试和技术文档。
- B：`src/scene/`、`src/game/`、对应测试与素材记录；配置需求交给 A。
- 共享：A 将接口 v1 转为 `src/contracts/` 类型及适配边界，B 审查。接口冻结以审查和合入为准。
- 坐标为游戏 CSS 视口左上角原点的归一化坐标；时间使用页面 `performance.now()`；来源保留 camera / simulated / manual。
- 接口包括 GazeSample、TargetRegion、GazeEvent、SceneEvent、TrainingCommand；字段和运行边界以现有接口文档为准。本阶段不新增 M4 摘要字段。

## 必须交付

- FR-01：TypeScript + Vite + Three.js 工程、锁文件及可复现运行说明。
- FR-02：共享类型与订阅/目标设置/场景命令适配边界；消费方不得直接访问对方模块内部实现。
- FR-03：显式 simulated 的样本与事件、诊断面板；无效信号不累积停留，禁用目标不确认，同次停留不重复确认。
- FR-04：一张偏写实森林地图与自动游览、暂停、恢复、重启；自然比例、材质、光照和植被层次遵循[视觉方向](visual-direction.md)。
- FR-05：3D 内部渲染最大 1920×1200，DPR 上限 1.25；控制植被、纹理和阴影。
- FR-06：真实安装、启动、类型检查、构建及必要测试命令写入 README、AGENTS 和 CI，未执行的步骤标为未验证。
- FR-07：截图、30～60 秒场景演示、加载时间、浏览器实际 GPU 和 FPS 记录，以及已知限制。
- FR-08：B 提供视觉参考板与营地、林间小径、溪流三个代表视角，记录人工审阅意见；M1 为初步样片，M4 继续细化同一地图。

## 验收门槛与依赖

新环境可启动且路线可完成，暂停和重启有效；A/B 各自交付 PR 合入，基础先合入；演示、性能记录、运行说明与模拟来源完整；联合验收和导师确认完成。打不开或路径无法完成则不通过。

场景单独争取 60FPS，此为目标，不能用估算代替实测。联合稳定 30FPS、真实摄像头精度与 15 分钟联合旅程属于后续阶段，本阶段不宣布这些项目通过。

## 不做的内容

不实现摄像头、MediaPipe、Worker 推理、个人校准或真实注视精度验收；不做注视驱动完整旅程、训练规则、持久化记录、多地图、社交、排名、LLM 或额外传感器。摄像头帧不上传、不保存。
