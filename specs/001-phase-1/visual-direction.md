# Phase 1 视觉方向：偏写实的山地森林

状态：视觉目标与实施建议，尚未实现或人工验收。依据用户 2026-10-03 的偏真实场景要求，更新此前“风格化森林”的表述。保留单地图、Three.js、现有渲染上限和阶段验收规则。

## 视觉定位

目标是接近日常徒步所见的自然森林：尺度可信、材质有细节、光照柔和、远近层次清楚。写实程度以浏览器实际性能为边界，M1 交付初步视觉样片，M4 在同一地图上细化。

建议基调为初夏山地混合林、白天柔和侧光、轻微远景薄雾；这是本次设计建议，并非参考资料给出的唯一答案。使用低饱和苔绿、树皮灰棕、泥土褐和偏灰蓝的远山，保留阳光照亮叶片时的局部暖色。避免统一高饱和绿色、塑料般高光、满屏浓雾和明显重复的树木阵列。

## 场景构成与代表视角

| 视角 | 构图和内容 | M1 需要呈现的写实线索 |
| --- | --- | --- |
| 营地出发 | 近处木质路标与碎石，中景营地和林缘，远景山脊 | 路标、树干和道路尺度一致；木材纹理方向合理；物体有落地感 |
| 林间小径 | 路径缓慢转弯，树干形成纵深，路边蕨类和苔石点缀 | 路面有泥土、碎石和落叶变化；树木大小、朝向、间距有变化；路径边缘自然过渡 |
| 溪流开口 | 近处溪岸石头，中景浅水与林地，远处山峰与天空 | 水面适度反光，溪岸与地形连接；远景对比逐渐降低；路线和路标仍清楚可见 |

树木按小群落和林间空隙布置，避免均匀撒满地面。近处保留树皮、岩石和地面细节，中远处逐步降低模型和纹理复杂度。M1 可用少量质量较好的树木变体重复组合，但在三个代表视角检查重复是否明显。

## 材质、光照与渲染

以 MeshStandardMaterial 的 PBR 工作流作为主要材质候选，使用 base color、normal、roughness 等贴图表达树皮、石头和土壤，而不是单靠增加模型面数。[Three.js 官方材质文档](https://threejs.org/docs/pages/MeshStandardMaterial.html)说明其基于物理的材质模型。

按实际贴图用途配置色彩空间：颜色贴图使用 sRGB，法线和粗糙度等数据贴图不进行颜色转换；统一曝光和输出流程，避免重复转换导致画面发灰或过亮。具体 API 以工程锁定版本为准。[Three.js 色彩管理指南](https://threejs.org/manual/pages/color-management.html)

优先使用一个太阳方向光和柔和环境补光，固定时段与曝光。只为路径附近重要物体配置必要阴影；阴影贴图需要额外渲染，应控制覆盖范围和投影物数量。[Three.js 阴影指南](https://threejs.org/manual/pages/shadows.html)

薄雾用于远景纵深，保持近处路标可读；可参考官方地形与雾示例的层次关系，但不直接将该示例当作完整森林方案。[Three.js terrain + fog 示例](https://threejs.org/examples/webgl_geometry_terrain.html)

M1 水面使用简单材质、轻微法线变化及适度环境反射即可。体积云、体积光、屏幕空间反射、动态昼夜和复杂水体不列为本阶段必交内容。先解决比例、构图、材质和光照，再根据实测决定是否增加后处理。

B 制作参考板：收集真实林地、林间小径、溪岸各类参考，分别说明借鉴的尺度、材质、光照或构图；同时展示三个代表视角的场景截图。优先使用与同一季节、地貌和光照相符的素材，避免拼出不协调的生态环境。

## 性能策略与开发顺序

1. 先用灰盒确认地形、路线、观察高度和三个代表构图。
2. 完成一小段林间路径的材质与光照样片，由负责人审阅后扩展到其余路线。
3. 加入少量树木变体、林下植物、溪岸和营地细节；使用固定随机种子，便于复现画面。
4. 对共享几何和材质的重复植被评估 InstancedMesh，配合距离分级与裁剪，减少绘制成本。[Three.js InstancedMesh 文档](https://threejs.org/docs/pages/InstancedMesh.html)
5. 初始纹理建议以 1K 为主，重点近景按需要使用 2K；这是待实测的起点，不是已验证预算。透明叶片避免大面积多层重叠，远处优先降低植被与阴影成本。
6. 按现有 1920×1200、DPR ≤1.25 上限实测；记录 FPS、draw calls、三角形数、纹理/几何数量和资源体积。不能将 renderer.info 的数量指标当作精确显存占用。

资源预算和画质降级由 B 根据真实测量提交说明，必要配置由 A 维护。保持现有场景 60FPS 目标，不因追求写实擅自改变后续联合性能门槛。

## 人工视觉审阅

三个固定视角及一段自动游览供负责人审阅：是否像自然森林、地面是否有细节、植物是否明显重复、物体是否悬浮、曝光是否过亮、远近层次是否清楚、路标是否容易辨认。运动中检查叶片闪烁、阴影抖动、模型突然切换和相机穿模。

这些是审阅项目，不替代已有 M1 通过条件。记录实际截图、修改意见与未解决项；不能用离线渲染、参考照片或概念图冒充运行画面。偏写实是已确认方向，具体时间、植被类型与色调可根据首次样片反馈调整。
